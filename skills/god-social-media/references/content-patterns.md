# Social Content Archetypes

| Archetype | Layout | Best on |
|---|---|---|
| Big-number stat | Giant number (40% of frame) + 1-line context + source | LinkedIn, IG |
| Quote card | Quote in display serif, attribution small, portrait optional | IG, LinkedIn, X |
| Before / after | Split vertical or horizontal, labelled | IG, Pinterest, TikTok |
| Listicle carousel | Hook → 1 tip per frame → recap → CTA | IG, LinkedIn |
| Tutorial steps | Numbered steps with screenshots in device frames | IG, Pinterest |
| Announcement | Product/visual hero + headline + date/CTA | All |
| Event poster | Title, date, venue, a strong graphic; 4:5 and 9:16 versions | IG, Stories |
| Meme / reaction | Familiar format, brand voice, minimal branding | X, IG, TikTok |
| Infographic pin | 2:3 tall, sections top→bottom, brand at bottom | Pinterest |
| Thumbnail | Face + object + ≤ 4 words | YouTube |
| Testimonial | Customer photo, short quote, name/role, stars | IG, FB, LinkedIn |
| Behind the scenes | Raw photo, light branding (lower third) | Stories, Reels |

**Hook copy formulas:** "Stop doing X", "X things I wish I knew about Y", "The 3-second rule for Z", "Why X fails (and the fix)", "[Number] [result] in [time]". Keep claims honest and specific.

**Series system:** a fixed grid position for the logo (e.g. bottom-left 48px margin), a fixed headline zone, a colour per content pillar (education = cobalt, case study = red, culture = green), and a consistent frame counter.
