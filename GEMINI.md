# God of Design (Gemini CLI / Antigravity context)

Contributors: the repository guide is in [AGENTS.md](AGENTS.md).

When this repo is loaded as a Gemini CLI extension, the design skills live in `skills/`. For any visual design task (web/UI, app screens, social posts, posters, logos, slides, motion, charts, image prompts), activate the `god-of-design` skill first. It routes to `god-styles`, `god-color`, `god-typography`, `god-ui-ux`, `god-social-media`, `god-print`, `god-branding`, `god-presentations`, `god-anti-slop`, `god-review` and others.

Always follow brief → one named direction → tokens → build → anti-slop and review gate. Target WCAG 2.2 AA, use exact values, avoid AI slop, and use cultural styles respectfully.
