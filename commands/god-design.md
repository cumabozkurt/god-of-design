Use the `god-of-design` skill and run its full five-step workflow for: $ARGUMENTS

1. Write a 3–5 line brief (infer what's missing; ask only if truly blocking).
2. Commit to one named aesthetic direction (use `god-styles`).
3. Define tokens (colour roles, type, spacing, radius, motion).
4. Build the artefact in the right format for the medium (`god-output`).
5. Run the `god-anti-slop` gate and a `god-review` self-score, fix the issues, then deliver with a short rationale.
